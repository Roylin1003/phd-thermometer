# 畢業溫度計 PhD Thermometer

*A collaborative project by roylin1003 and Claude.*

師大華教系博士班修業進度自我檢查工具。選組別（產學研發組／華語文教學組），勾選已完成項目，溫度計即時反映完成比例；未滿足前置條件的項目會鎖住，並顯示缺項清單。純 HTML，不需安裝、不需伺服器。

**▶ 立即使用**：〈Cloudflare 網址（phd-thermometer.roylin1003.workers.dev）——上線後回填〉

> 依系上修業規定（112 學年修訂版）整理，供進度自我檢查，**不具正式效力**，實際條件以系辦公告與正式規定為準。

---

## 功能

- 兩組別各自獨立的檢查項目、條文引用（§ 對應修業規定條號）
- 依賴鎖定：未完成前置項目時後續項目無法勾選；取消前置項目時已勾選的後續項目自動解除
- 畢業學分需求可調（預設 21 學分，對應 112 學年版），連動所有引用學分數的文案
- 資格考通過（§11）即顯示候選人資格徽章
- 勾選狀態與學分數存於瀏覽器 localStorage，兩組別分開儲存、互不覆蓋
